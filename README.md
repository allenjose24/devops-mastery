# DevOps Mastery

A public, ground-up record of building deep DevOps engineering expertise —
not just "learn the tool," but understanding the Operating Systems, Networking,
and Computer Science fundamentals every DevOps tool is actually built on.

## Why this repo exists

Most DevOps roadmaps teach commands. This one insists on also answering
*why the command works* — tagging every concept back to the underlying
fundamental (OS, Networking, DBMS, Algorithms, Security, Performance)
wherever a genuine connection exists.

## How this repo is organized

- **This repo** contains the finished study material — one PDF per module,
  organized by phase, containing the full taught content, mindmaps, tables,
  and notes.
- **The [Wiki](../../wiki)** contains the topic-map for every module — the
  structured curriculum (what to learn) before it was taught and compiled
  into the PDFs here.
